# VAPT Capstone Portfolio

## About

This repository documents my hands-on learning and practical work in Vulnerability Assessment and Penetration Testing (VAPT). It contains security assessment reports, lab exercises, findings, proof-of-concept evidence, and remediation recommendations.

## Objectives

- Practice identifying and validating security vulnerabilities in authorized lab environments.
- Understand vulnerability severity, impact, and remediation.
- Document findings in a clear, structured penetration testing report.
- Improve practical skills in web application and network security testing.

## Tools and Technologies

- Burp Suite
- OWASP ZAP
- Nmap
- Nessus
- Metasploit Framework
- Kali Linux
- Wireshark

## Areas of Practice

- Web application security testing
- OWASP Top 10 vulnerabilities
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Broken Access Control and IDOR
- Network scanning and service enumeration
- Vulnerability assessment and remediation

## Report Structure

My security reports may include:

1. Vulnerability name and affected target
2. Description and technical details
3. Severity and CVSS score, where assessed
4. Proof of concept and supporting evidence
5. Potential impact
6. Recommended remediation

## Repository Contents

Explore the folders and files in this repository for the reports, lab exercises, screenshots, and evidence actually included in the project. The exact contents may change as I add more assessments.

## Disclaimer

All testing is performed in authorized lab environments or on systems for which permission has been granted. This repository is intended for educational and defensive security purposes only.
